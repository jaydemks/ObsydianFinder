MD4C, version 0.5.3

Source: https://doc.qt.io/qt-6/qtgui-attribution-md4c.html

A CommonMark-compliant Markdown parser.

Optionally used in QTextDocument if configured with textmarkdownreader.

The sources can be found in qtbase/src/3rdparty/md4c.
