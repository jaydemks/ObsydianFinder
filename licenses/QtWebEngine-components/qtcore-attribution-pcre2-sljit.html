PCRE2 - Stack-less Just-In-Time Compiler, version 10.47

Source: https://doc.qt.io/qt-6/qtcore-attribution-pcre2-sljit.html

The PCRE library is a set of functions that implement regular expression pattern matching using the same syntax and semantics as Perl 5.

Used in Qt Core (QRegularExpression).

The sources can be found in qtbase/src/3rdparty/pcre2/deps/sljit.
