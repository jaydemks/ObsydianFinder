Macros for Building with CMake

Source: https://doc.qt.io/qt-6/qt-attribution-cmake-macros.html

The following files contain macros that enable users to build Qt-based projects using CMake.

  • qtbase/src/corelib/Qt6CoreMacros.cmake
  • qtbase/src/dbus/Qt6DBusMacros.cmake
  • qtbase/src/widgets/Qt6WidgetsMacros.cmake
  • qttools/src/linguist/Qt6LinguistToolsMacros.cmake
